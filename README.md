## Problem
Teachers generate assignment questionare using AI
Students submit solutions generated by AI
Learning fades away


## Proposed Solution
On student's end -> create .md UI that tracks user inputs and captures paste events
etc etc and teachers can see logs like time heatmap, video replay of doc, major paste chunks


On teacher's end->They can generate questionares using AI and mark the assigments
they define a rubrics on which AI generates questionares and marks the submissions
It doesn't replace teachers it assists them

The results produced by teacher [marking] will be reiewed by teacher
teachers get to make the final call
